# Sprint 34：F07 实物收货地址与收货完成

## 1. 主台账编号与子范围

- 主台账编号：F07（实物收货地址与收货完成）
- 实际子范围：
  1. 实物订单建单地址快照：收件人、手机号、省市区、详细地址四项，写入 `trade_order`。
  2. 店铺固定运费：`merchant_store.shipping_fee`，实物单计入实付，不计入服务费计费基数。
  3. 买家确认收货：`POST /api/v1/public/orders/confirm-receipt`，`SHIPPED → COMPLETED`。
  4. 发货超期自动完成：`OrderAutoCompleteJob` 扫描超过阈值的已发货实物单。
  5. 售后期：自订单完成时间起算，超期拒绝新退款申请与新投诉，买家端展示售后截止时间。
  6. 三端页面：商城下单地址表单与运费明示、查单页收货信息/确认收货、管理端订单地址展示、商家资料页运费配置。

## 2. 代理自行细化的规则（待业务确认）

| 细化规则 | 性质 | 说明 |
| --- | --- | --- |
| 仅 `goodsType=1` 实物订单需要收货地址 | 业务规则细化，待业务确认 | 卡密（2）与定制服务（3）不展示、不提交、不落库地址字段 |
| 收件手机号仅接受中国大陆手机号 `1[3-9]\d{9}` | 校验实现细化 | 与买家联系方式字段分离；如需座机/国际号码须扩展规则与前后端文案 |
| 详细地址 5–200 字、姓名≤32、省市区≤64 | 校验实现细化 | 前后端同口径；超限/空值 400 且不回显原始输入 |
| 运费为店铺每单固定金额，0=包邮 | 业务规则细化，待业务确认 | 未实现按地区/重量/件数阶梯计费与包邮门槛；上限 1000 元防误填 |
| 运费计入实付与商家应收，不计入服务费基数 | 财务口径细化 | `shippingAmount` 单列快照；`feeBaseAmount` 仅商品成交额；订单明细 `subtotal` 仅商品金额 |
| 发货后 10 天自动确认收货 | 业务规则细化，待业务确认 | 从 `delivery_time` 起算；缺发货时间的历史单不自动完成 |
| 订单完成后 15 天内可申请退款/投诉 | 业务规则细化，待业务确认 | 从 `finish_time` 起算，截止时刻视为过期；缺完成时间的历史单不做时效拦截 |
| 自动完成跳过待审批退款与未结投诉 | 安全实现细化 | 避免争议处理中把订单置为完成；状态迁移用 CAS 要求仍为 `SHIPPED` |
| 确认收货重复提交幂等 | 技术实现细化 | 已 `COMPLETED` 返回成功且不覆盖 `finish_time`；非 `SHIPPED` 返回 409 |
| 商家推单地址四项全空可暂不采集 | 过渡实现细化 | 任一项非空则四项必须齐全；未采集的实物单在管理端明确提示“未采集收货地址（历史单）” |
